# admin.scopera.ai ist reine Infrastruktur: Kontaktformular-Endpunkt, Besucher-Beacon,
# Apollo-Webhook und das interne Admin-UI. Nichts davon gehoert in eine Suchmaschine.
#
# Warum die Suchmaschinen einzeln stehen: Cloudflare stellt dieser Datei seit Kurzem eine
# verwaltete robots.txt voran ("Content Signals"), die "User-agent: * / Allow: /" enthaelt.
# Gleichlautende Gruppen werden zusammengefuehrt, und bei gleich spezifischen Regeln gewinnt
# Allow - ein blosses "User-agent: * / Disallow: /" hier waere also wirkungslos. Eine Gruppe
# mit konkretem Namen schlaegt dagegen die Sternchen-Gruppe und bindet.
#
# Zusaetzlich sendet der Worker auf allen von ihm beantworteten Pfaden X-Robots-Tag: noindex,
# und /admin/* liegt ohnehin hinter Cloudflare Access.
