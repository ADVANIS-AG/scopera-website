Rückmeldung simulieren

      

        Durchläuft denselben Weg wie ein echter Besuch, ohne auf einen zu warten: Felder zuordnen,
        Konto über Name oder Domain suchen, Felder schreiben. Der Probelauf ändert nichts. Die
        Testrückmeldung schreibt Score 0, den aktuellen Zeitpunkt und einen erkennbaren Testtext in
        das gefundene Konto. Am besten ein eigenes Konto nehmen, z.B. ADVANIS.
