The old trade-off went like this: either a web application that runs everywhere and does little. Or native apps for iOS, Android and desktop that do a lot and cost a lot. Three codebases, three release cycles, three times the maintenance.

## What is possible today

- **One application, every device**: The same interface adapts from desktop to phone. It gets built once.
- **Access to device functions**: Camera, location and sensors are available where they are needed. The LiDAR room scan is one example.
- **No rollout**: No installation, no versions on devices, no waiting for app store approval.

## Where the limit is

Some use cases still call for a native app. Graphics-heavy work is one of them. For business applications inside a company that is rarely the case. We push what works without separate native development, and we say so openly when a requirement goes beyond it.

## Where to start?

Check which of your mobile workflows really need device functions. Usually it is camera and location. Both are covered.
